## What's new in 1.6.0

- **Command palette.** Press **Ctrl+Alt+P** (or Ctrl+Alt+Space when it's free), or click "Search or run…" at the top of the sidebar. Type to jump to any page, run actions (Game Mode, clean junk, screenshot, flush DNS, restart Explorer…), launch games and any Start-menu app, or end a stuck window. Type a sum like `1920*1080` to calculate it. Anything else can go straight to Ask AI.
- **Ask AI.** Ask questions like "why is my PC slow right now?" and get an answer based on a live snapshot of your PC: load, memory hogs, disk space and PC Optimizer's own checks. Uses Claude with your own Anthropic API key, stored encrypted for your Windows account and never included in setup exports.
- **Change the clip and screenshot hotkeys.** On Clips & Screenshots, click a key and press the combination you want. If another app already uses one, the page tells you.

### Fixes
- Clipboard history text was hard to read (dark on dark). It's now clear in both the page and the Ctrl+Alt+V pop-up.
- The Uninstaller no longer freezes the first time you open it; it also loads quietly in the background after start-up.
- The "Standard mode" note at the bottom of the sidebar no longer gets cut off.

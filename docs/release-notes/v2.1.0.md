## Rig 2.1.0

The capture-studio update: replay clips, manual recording, audio, and a local clip library.
Rig 2.0.0 remains available as the preserved previous release. Both versions have one **Rig.exe** download.

### Capture the moment
- Rig now has its own replay buffer. Enable it before playing, then save the last 15–120 seconds.
- Start and stop manual recordings, including while replay stays enabled. Record a display or choose an area.
- Capture game/system audio with an optional microphone. Choose devices and adjust their volumes separately;
  saved video contains a mixed audio track. Microphone capture and automatic replay start off.
- Choose a quality preset or customize resolution, 30/60 FPS, bitrate, cursor visibility, display, and save folder.
- H.264 hardware encoding is selected when supported, with a software encoder available as fallback.
- Search your local library, filter by type, mark favourites, play videos, trim a new copy, or export a short GIF.
- Replay storage rolls over automatically. Interrupted manual recordings retain recovery segments; Windows ties
  capture processes to Rig's lifetime so a crash doesn't leave a hidden recorder running.

### Make Rig yours
- Drag Home cards to reorder them. Keyboard users can use the edit card's context menu.
- Input Stats updates once a second while visible. Mouse and click maps use a finer grid with smooth hotspots;
  existing heatmap counts are retained.
- Six theme modes, twelve accent presets, custom colours, glow and corner options, all applied without restarting.
- Click to edit every global shortcut, including the palette and clipboard. Windows-key combinations, conflict
  detection, resetting, and unbinding are supported. Beta updates were removed from Settings.

### Details
- Windows 10/11, 64-bit. Rig.exe includes the runtime and pinned recording components.
- Capture files stay local. Replay records the selected display, including other apps on that display. Protected
  content and some exclusive-fullscreen games may require a different display mode or may not be capturable.
- GIFs have no audio. Video audio is mixed rather than separate editable microphone/game tracks.
- If you installed the earlier build already numbered 2.1.0, download this new 2.1.0 manually once.
- Rig.exe is not Authenticode-signed. Third-party components and sources are listed in Settings and
  [THIRD-PARTY.md](../THIRD-PARTY.md).

## Rig 2.1.0

A clearer Home and a redesigned Game Mode, with one standalone **Rig.exe** download for Windows 10 and 11 (64-bit).

### Home, focused on what you use

- Game Mode now leads Home, with clear manual, automatic, active, starting, restoring, and recovery states.
- Compact CPU, memory, and uptime cards keep live readings together.
- Edit shortcuts directly from Home. Recent tools shows your last four tools for this session, in memory only.
- Maintenance lists findings to review instead of a headline score. Cleanup suggestions open Junk Cleaner for review.
- Customized layouts stay intact; only the previous factory layout moves to the new arrangement.

### Game Mode, easier to understand

- Session status, automatic detection, profiles, and session defaults are visible up front.
- Advanced detection, background apps, overlay, and session history are tucked into expandable sections.
- Choose an installed game when creating a profile, or type a custom name. Installation-folder matching keeps
  preferences tied to the right copy of a game. Existing name-only profiles still work.
- Profiles begin with your current defaults and open for editing. Changes apply the next time Game Mode starts.
- Active sessions show the changes actually applied. Failed restoration stays visible with a retry action.
- Settings search opens collapsed sections before revealing the result.

### A cleaner first impression

- Keeps the redesigned three-step setup: install or portable, essential preferences, and optional tracking choices.
- Refreshed GitHub images come directly from Rig's WPF interface, with sample data and no desktop cursor.
- One release, one full app: **Rig.exe** includes the .NET runtime. There is no Lite edition or legacy-named download.

### Updating

Rig 2.0.0 users can check for updates in Settings. If you used an experimental build already numbered 2.1.0,
download this release manually once. Your settings remain separate from the executable.

The app build passes with warnings treated as errors, and all 90 isolated automated tests pass. Live display and
power-plan changes are not newly certified by this interface release. Rig.exe is not Authenticode-signed.

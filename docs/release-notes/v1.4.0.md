## What's new in 1.4.0

- **Install it properly.** The first time you open PC Optimizer, a short welcome sets up Game Mode and startup, then installs it to your user folder with a Start menu shortcut (and a desktop one if you want). It shows up in Windows' "Installed apps", and uninstalls cleanly from there. You can still choose to keep it portable.
- **Performance overlay.** A small, click-through CPU / GPU / RAM / ping readout in a corner of your screen while Game Mode is on. Turn it on and preview it on the Game Mode page.
- **Security page.** Windows Defender at a glance: protection status, quick or full scan, update definitions, and (in admin mode) exclude your game folders from real-time scanning.
- **Maintenance night.** Pick a day and hour (Tools page) and PC Optimizer cleans junk and checks app updates once a week, even if your PC was off at that time. It skips itself if you're gaming and leaves you a summary.
- **Crash reporting.** If something goes wrong you get a clear message instead of the app vanishing, with "Copy details" and a link to report it. Logs are kept in `%AppData%\PCOptimizer\logs`.
- Releases are now built automatically on GitHub.

**Download:** `PCOptimizer.exe` if you're not sure. `PCOptimizer-lite.exe` needs the .NET 10 Desktop Runtime. Already on 1.3? The app offers the update itself.

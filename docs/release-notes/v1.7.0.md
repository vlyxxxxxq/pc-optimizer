## What's new in 1.7.0

- **Crosshair.** A custom crosshair (5 styles, any colour, size, gap, outline) that turns on by itself in the games you pick and off when you alt-tab or close them. Ctrl+Shift+F8 toggles it anywhere (changeable). Works over borderless/windowed games; check your game's rules before using it in ranked.
- **Controller Tester.** See every button, stick and trigger live, check for stick drift, and test the rumble motors. Xbox controllers and anything that acts like one.
- **Session recap.** When a game closes you get a card with playtime, load, game RAM and clips captured, plus average FPS and 1% lows in admin mode.
- **Game news.** Library covers show a NEW badge when the developer posted an update this week; right-click → What's new for the patch notes (Steam games).
- **Free games radar.** Game Library lists free-to-keep games on Epic, Steam, GOG and more, with a notification when a new one appears.
- **Downloads organizer.** Sort loose files in Downloads into folders by type, with undo, optional automatic sorting, and a list of old installers to clear out.

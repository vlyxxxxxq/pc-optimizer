## Rig 2.0.0

The preserved Rig release from before the capture-studio update, rebuilt with the 2.0.0 version number.

- Redesigned Home with shortcuts, maintenance findings, recent tools, and customizable cards.
- Game Mode with installation-specific game profiles, session defaults, and restoration recovery.
- Three-step setup with install or portable choices and explicit optional tracking preferences.
- The existing screen recorder, screenshots, and Game Bar replay integration.

Download **Rig.exe** for Windows 10 and 11, 64-bit. It includes the .NET runtime.
Your settings are stored separately from the executable. This release remains available alongside Rig 2.1.

For Rig's new replay buffer, game audio, microphone controls, clip library, trimming, live themes, and draggable
Home cards, choose Rig 2.1. Rig 2.0.0 is not Authenticode-signed.

# Rig 2.0.0

**Your PC, at your fingertips.**

One Windows toolkit. One standalone download. Rig brings Game Mode, file tools, and everyday utilities together
in a native desktop app.

## Download

Download **Rig.exe** below for **64-bit Windows 10 or 11**. The runtime is included—there is no separate .NET
installation and no second app edition to choose from.

Open it to choose **Install Rig** or **Run portable**. Installation is for your Windows account and does not
require administrator access. Certain system tools need elevation when you use them.

## A better first five minutes

- A new setup flow puts the installation choice first, shows the destination, and explains portable storage.
- Review automatic Game Mode, sign-in startup, notifications, clipboard history, and screen time before applying them.
- Tracking features start off. A desktop shortcut is optional.
- See real installation progress and a completion screen. Errors stay in setup with a retry option.
- Closing setup cancels rather than opening the app with unreviewed defaults.

## A toolkit that fits your day

- **Home:** pinned tools, a maintenance checklist, live system information, customizable cards, and a compact preset.
- **Gaming:** automatic Game Mode, per-game profiles, a game library, controller testing, crosshairs, and session recaps.
- **Files:** Downloads organization, disk-space analysis, cleanup, Similar Photos, batch renaming, and file recovery.
- **Everyday tools:** clipboard history and notes, timers and reminders, window layouts, a color picker and ruler,
  screenshots, and MP4/GIF screen recording.
- **System tools:** startup apps, processes, app updates, hardware, network checks, and Windows maintenance.
- **Search:** find tools and settings, launch apps, calculate, convert units, and set reminders from the command palette.

## Reliability and control

Game Mode records changes and keeps failed restoration work available for retry. File moves and renames keep recovery
records, including unresolved undo conflicts. Similar Photos separates exact duplicates from look-alikes, which are
not preselected for removal. Backups preview what will be imported, and settings use atomic saves with a backup copy.

The updater checks download size and published checksums and supports startup rollback. Signed release verification
is available in the code but is not configured for this release. Rig.exe is also not Authenticode-signed, so Windows
may display an unknown-publisher warning.

## Useful details

- Installed app: `%LocalAppData%\Programs\Rig`.
- Settings and enabled history: `%AppData%\Rig`, in both installed and portable modes.
- Clipboard history stays in memory and clears on exit.
- The built-in screen recorder captures video without audio; recent gameplay clips use Game Bar.
- Closing the window normally keeps Rig in the tray. Choose **Exit** from the tray menu to quit completely.

## Updating an earlier copy

This is a version reset to **2.0.0**. Earlier 2.0.0 and 2.1.0 builds do not see it as a newer automatic update.
Quit the running copy, download Rig.exe, and replace the old EXE once. Settings remain in their separate data folder.
Migration support for earlier settings is retained.
